# Power Move Insights

Build Power Move IQ as a premium mobile-first full-stack decision-intelligence web app.

BRAND
Name: Power Move IQ
Tagline: KNOW YOUR NEXT MOVE.
Visual identity: black, ivory and antique-gold; refined editorial serif/sans typography; cold, premium, restrained, high-fashion editorial feel. Use an owl emblem/medallion placeholder area without inventing a different owl identity; the approved owl asset will be supplied separately. Avoid generic SaaS gradients, bright startup colors, cartoon graphics, or motivational-coach aesthetics.

PRODUCT
Power Move IQ helps people think through difficult professional and money situations: client negotiations, pricing, salary/raise conversations, difficult customers, boundaries, stalled negotiations, being undercut, ghosting, offers/counteroffers, and deciding when to walk away.

Primary homepage:
POWER MOVE IQ
KNOW YOUR NEXT MOVE.
"When the stakes change, don’t guess. Map the situation, understand your leverage, and choose your next move."
Primary CTA: ANALYZE MY SITUATION

Under it show situation chips:
They lowballed me
Client went silent
I need a raise
I’m being undercut
Negotiation stalled
They called my bluff
I need to say no
Should I walk away?

CORE ANALYSIS WORKFLOW — MOVE IQ™
Create an input experience where a user describes a situation, then present a polished structured result:
1 THE READ — objective situation; separate facts from assumptions.
2 POWER MAP — user leverage, other-side leverage, constraints, unknowns.
3 YOUR MOVES / THE MOVE — strongest viable options and tradeoffs.
4 THE SCRIPT — exact adaptable language.
5 COUNTERMOVES — If they do X → consider Y.
6 DON’T DO THIS — highest-risk move or weakening action.
7 EXIT LINE — when disengaging/walking away is strategically reasonable.
8 WHAT HAPPENED? / OUTCOME MEMORY™ — let the user return and record accepted, negotiated, declined, ghosted, or other; preserve situation, recommendation, chosen move and result.

Build authentication and a user dashboard with Saved Cases and Outcome Memory history. Create a Daily Move section/library architecture for 90 moves, streak display, saved moves, share action, and Weekly Strategy Lens. Seed the UI with several original professional negotiation examples; do not copy copyrighted strategy-book text.

MONETIZATION
Free: Daily Move plus limited/sample MOVE IQ.
Pro: $14.99/month or $99/year.
Pro unlocks full MOVE IQ analyses, Power Maps, scripts, countermoves, saved cases, Outcome Memory, follow-up analysis and Weekly IQ.
Build the pricing/paywall UI and entitlement architecture. Do not invent live Stripe credentials; leave payment integration ready to connect securely.

NAVIGATION
Today / Analyze / Library / Saved / About / Account.
Mobile-first bottom navigation where appropriate; refined desktop navigation.

DATA
Provision the app so authentication, saved analyses, chosen moves, outcomes, favorites and streak state can persist in the database. Use secure per-user access patterns.

COPY/LEGAL
Educational decision-support, not professional legal/financial advice. Include About, Privacy, Terms, cancellation/subscription language placeholders, and this independence concept: Power Move IQ is an independent project and is not affiliated with Donald J. Trump, the Trump Organization, any campaign, or Robert Greene. Avoid endorsements.

QUALITY BAR
This must feel like a $10M+ premium editorial product, not a template. Strong whitespace, precise hierarchy, subtle gold rules, excellent mobile spacing, accessible contrast, restrained microinteractions. Build a coherent functional MVP now, not just a landing-page mockup.
